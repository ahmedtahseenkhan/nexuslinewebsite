FAQ

Frequently asked questions.

Can NexusLine run entirely on-premise or air-gapped?

Yes. The same platform runs as managed cloud or entirely inside your own data centre, including air-gapped networks, and the capability set is identical. On-premise installs are updated with versioned images, migrations and an offline bundle, and use offline Ed25519-signed licences with no phone-home. Compare deployment options.

Which frameworks come preloaded?

Seventeen frameworks with 1,333 clauses, including ISO 27001:2022, NIST CSF 2.0, NIST SP 800-53, PCI DSS 4.0, SOC 2, Basel operational risk, Shariah governance and four SBP packs. Control frameworks bring their controls with them, and crosswalks let one control satisfy requirements across frameworks. Browse the module catalogue.

Does document intelligence send our documents to a third party?

Not unless you configure an external AI API key. Without one, a deterministic on-device engine does the extraction, so no data leaves the building — which is how air-gapped installations use the feature. How document intelligence works.

How is our data isolated in the managed cloud?

Each organisation’s data is segregated per tenant and isolated in the database with PostgreSQL row-level security (FORCE RLS), so even a compromised query cannot cross organisational boundaries — it fails closed. Data is encrypted in transit and at rest, and access is governed by SSO, MFA and 96 granular permissions. Security & audit.

How long does it take to get started?

Onboarding is five steps: choose your locale, frameworks and modules — pre-selected for your institution type — then invite your team. Managed cloud is the fastest way to launch. For a demo, tell us which frameworks you run and we will load them into a live environment.

How is NexusLine priced?

Pricing depends on the editions you choose — each organisation picks which modules its teams see. Managed cloud is a subscription; on-premise uses an offline, signed licence that lists your editions. Email info@nexusline.io or request a demo for a quote.
